# Secure Ticketing System for IT Helpdesk

## Project Title and Overview
This is a web-based ticketing system for an IT helpdesk. After logging into the website, the employees will be able to create a ticket, view only their tickets, update it and approve the ticket to be closed once the issue is resolved or reopen it if the issue is not resolved. The IT helpdesk staff(admin and agents) will be able to assign the ticket, work on the ticket, resolve it and delete the duplicate tickets.

There will be 3 types of account in this website.
- Employee account - Create the ticket, View the ticket, Update the ticket, Approve the ticket for closure.
- Agent account - Can view only the assigned tickets, Update it, Set the ticket to resolved status.
- Admin account - Create and manage the accounts, Can view all the tickets, Can assign the tickets to agents, Delete the duplicate tickets.

This website will be built with security as the core idea and not just an add-on. The major security focus for this project will be - Authentication to prove who is logging in, Authorization to define what each role is capable of, Session Management to make sure the users stay logged in safely, Data Validation to secure against attacks like SQL injection and Cross-site scripting.

I will be using technologies like Python, Django and SQLite in order to build this project.
